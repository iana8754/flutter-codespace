# Taxi App — T1 Driver + T2 Passenger

Два Android-приложения Flutter, связанные Supabase.

## GPS
- Пассажир запрашивает реальную геопозицию телефона и использует её как точку подачи.
- Водитель включает режим «В сети», приложение получает координаты GPS и публикует их в Supabase.
- Координаты водителя обновляются в таблице `driver_locations`; пассажир получает их через Supabase Realtime и видит автомобиль на карте.
- Передача координат работает, пока приложение водителя открыто и включён режим «В сети». Фоновое отслеживание при свёрнутом/закрытом приложении пока не включено.

## Навигация и пробки
Для полноценной встроенной навигации выбран 2ГИС Flutter SDK Full. Он предоставляет маршруты с учётом текущих пробок, навигацию turn-by-turn, альтернативные маршруты и голосовые подсказки.
Для подключения необходимы ключи 2ГИС с разрешёнными Maps, Directions и Navigation API; ключи создаются в кабинете 2ГИС.
Документация: https://docs.2gis.com/en/flutter/sdk/overview и https://docs.2gis.com/en/flutter/sdk/examples/navigation.
Пока ключ 2ГИС не добавлен, в приложении остаётся демонстрационная карта и тестовый маршрут. Не выдавать OSRM или расчёт по времени суток за реальные пробки.
