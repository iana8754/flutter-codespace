# Taxi App

Чистая основа Flutter/Dart-проекта для двух приложений такси: пассажира и водителя.

## Технологии
- Flutter / Dart
- 2ГИС Flutter SDK Full
- Supabase
- Geolocator

## Запуск
```bash
flutter pub get
flutter run
```

Файл ключа 2ГИС должен находиться в `assets/dgissdk.key`. Он исключён из Git через `.gitignore` — не загружайте его в репозиторий.

Расширения Dart и Flutter для VS Code подключаются через `.devcontainer/devcontainer.json`.
