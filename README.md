# Taxi App — T1 Driver + T2 Passenger

Два Flutter Web-приложения на Dart, связанные одной базой Supabase.

## Запуск в GitHub Codespaces

Сначала установите зависимости:

```bash
flutter pub get
```

**T2 — пассажир** (терминал №1):

```bash
flutter run -d web-server --web-hostname 0.0.0.0 --web-port 8080
```

**T1 — водитель** (терминал №2):

```bash
flutter run -d web-server -t lib/driver_main.dart --web-hostname 0.0.0.0 --web-port 8081
```

Откройте вкладку Ports в Codespaces и перейдите по портам 8080 и 8081. Создайте отдельный аккаунт пассажира в T2 и водителя в T1.

## Реализовано

- Регистрация и вход с разделением ролей.
- Создание заявки пассажиром и отображение её водителям в реальном времени.
- Принятие заявки водителем.
- Изменение статусов: принят, водитель едет, поездка началась, завершена.
- Общая база Supabase и Realtime.
- Карта OpenStreetMap и построение демонстрационного маршрута через OSRM.
- Предварительный расчёт расстояния, времени и цены.

## Ограничения текущей демонстрационной версии

- Карта пока использует тестовый маршрут в Риге; поиск адресов и выбор точек нажатием на карту ещё не реализованы.
- Геопозиция водителя демонстрационная: реальный GPS и отображение движущегося автомобиля пассажиру ещё не подключены.
- Пробки рассчитываются упрощённо по времени суток. Это не реальные данные о дорожном движении.
- Цена — примерная формула в евро, её нужно настроить под нужный город и валюту.
- Для промышленного запуска необходимы реальный Traffic/Routing API, серверная атомарная обработка принятия заказов, дополнительная защита RLS и проверка водителей.

## Supabase

Созданы таблицы `profiles`, `rides`, `driver_locations`. Для них включён RLS; изменения поездок передаются через Supabase Realtime. В клиентском приложении используется только publishable key. Service-role ключ нельзя помещать во Flutter Web.
